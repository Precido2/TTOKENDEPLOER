Creator rules
          

            

            

          

          

        

      

      

        
Create a chest run world for a token

        

          

          

          

          

          

        

        

        
Every entry fee is added to the pot. A run collects up to 24 chests: common 0.1–0.3% of the pot, rare 0.3–0.8%, epic 0.8–2%, legendary 2–6%. Three to five random events hit each run and take 8–30% of what a player is carrying. One run can never pay out more than 15% of the pot.
